# Classroom Management App

A simple classroom management application built with React, Node.js,
Express and Firebase.

## Features

### Instructor

- Add students
- Edit student information
- Delete students
- Assign lessons
- Chat with students

### Student

- View assigned lessons
- Mark lessons as done
- Edit profile
- Chat with instructor

## Authentication

The application supports SMS access codes and student account setup
through email verification.

## Tech Stack

- React
- Node.js
- Express
- Firebase / Firestore
- Socket.io
- Twilio
